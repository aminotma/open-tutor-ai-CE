# Exercise Tools — Documentation

> Package: `open_tutorai.tools`
> Used by: `ExerciseAgent` ([exercise.py](../backend/open_tutorai/agents/langgraph/agents/exercise.py))
> Generated by: `generate_typed_exercises()` ([helpers.py](../backend/open_tutorai/agents/helpers.py))

---

## Overview

Tools are **automatically activated** as soon as a subject is resolved. The full flow is:

```
TutorGraphState
    └── subject / detected_subject
            │
            ▼
    ExerciseAgent — subject resolution cascade
            │
            ├─ generate_typed_exercises()   ← resolved subject → exercises with trigger fields
            │       └── _run_tool_for_exercise()  → tool call based on (type, subject)
            │
            └─ generate_exercises()         ← generic fallback (no tool)
```

---

## Subject resolution — 3-source cascade

The `ExerciseAgent` resolves the active subject in this order (first non-empty value wins):

| Priority | Source | Field | Who fills it |
|---|---|---|---|
| 1 | Declared by the user | `state['subject']` | Frontend / Gateway API |
| 2 | Inferred by DiagnosticsAgent | `state['detected_subject']` | `detect_subject(topic, weak_concepts)` |
| 3 | Local heuristic | result of `detect_subject()` | ExerciseAgent itself |
| — | Fallback | `None` | → generic `generate_exercises()` |

### `detect_subject(topic, weak_concepts)` — [helpers.py](../backend/open_tutorai/agents/helpers.py)

Detects the subject by multilingual keyword matching (fr, en, ar, es).
Requires **≥ 2 hits** to avoid false positives on short topics.

| Returned subject | Example trigger keywords |
|---|---|
| `cs` | algorithm, code, python, recursion, boucle, fonction, sorting |
| `math` | intégrale, dérivée, équation, matrix, vector, probability, limit |
| `science` | physique, chimie, énergie, atom, reaction, electricity |
| `language` | grammaire, conjugaison, dictée, spelling, translation, vocabulary |
| `history` | révolution, guerre, siècle, timeline, geography, civilization |
| `None` | topic too short or ambiguous → generic fallback |

## Tool routing — full table

| Exercise `type` | `subject` | Tool called | Trigger field |
|---|---|---|---|
| `coding` | `cs` / any | `live_code_evaluation` | `starter_code` present |
| `math` | `math` / `science` | `math_evaluator` | `expression` or `answer` present |
| `chart` | any | `generate_chart` | `chart_type` + `chart_payload` present |
| `dictation`, `writing` | `language` | `grammar_checker` | `sample_text` or `answer` present |
| `mcq`, `explain` | any | `search_web` | `search_query` present |
| `mcq`, `explain` | any | *(none)* | no `search_query` → LLM only |

## Typed generation by subject — `generate_typed_exercises()`

Called automatically by the ExerciseAgent when a subject is resolved.
Produces exercises with all **tool trigger fields** according to `(subject, level)`.

| `subject` | `level` | Generated `type` | Activated tool |
|---|---|---|---|
| `cs` | beginner / intermediate / advanced | `coding` | `live_code_evaluation` |
| `math` | all | `math` | `math_evaluator` |
| `science` | beginner / intermediate | `math` | `math_evaluator` |
| `science` | advanced | `chart` (function) | `generate_chart` |
| `language` | all | `dictation` | `grammar_checker` |
| `history` | all (alternating) | `chart` (timeline) or `mcq` | `generate_chart` / `search_web` |

---

## Fields produced by `generate_typed_exercises()`

```python
{
    # Common fields (all types)
    "id":           str,   # short UUID generated automatically
    "type":         str,   # 'coding' | 'math' | 'chart' | 'dictation' | 'mcq'
    "subject":      str,   # 'cs' | 'math' | 'science' | 'language' | 'history'
    "difficulty":   str,   # 'beginner' | 'intermediate' | 'advanced'
    "question":     str,   # localized based on state['language']
    "hint":         str,   # localized based on state['language']
    "answer":       str,   # localized or sympy value / corrected text
    "skill_target": str,   # targeted pedagogical objective

    # Type-specific fields — present only when the type requires it
    "starter_code":   str,   # coding — valid and executable Python stub
    "code_language":  str,   # coding — 'python' (default)
    "expected_output": str,  # coding — expected output (optional)

    "expression":  str,      # math — sympy expression (e.g. "solve(x**2-4, x)")
    "expected":    str,      # math — expected result (optional)

    "chart_type":    str,    # chart — 'function' | 'timeline'
    "chart_payload": str,    # chart — serialized JSON (see generate_chart schemas)

    "sample_text": str,      # dictation — sentence to be corrected by grammar_checker
    "lang_code":   str,      # dictation — BCP-47 code ('fr','en','ar','es')

    "search_query": str,     # mcq — query sent to search_web
}
```

## Tool 1 — `live_code_evaluation`

**File:** [live_code_evaluation.py](../backend/open_tutorai/tools/live_code_evaluation.py)

**Usage:** Computer science, algorithmics, numerical sciences (numpy/scipy).

**Triggered when:** `type == "coding"` AND `starter_code` present.
→ Produced automatically by `generate_typed_exercises(subject="cs")`.

**Dependencies:** Python stdlib (`subprocess`, `sys`) — no installation required.

### Parameters

| Parameter | Type | Description |
|---|---|---|
| `code` | `str` | Python code to execute |
| `language` | `str` | Language (`"python"` only for now) |

### Return

```python
{
    "success":  bool,   # True if exit code == 0
    "stdout":   str,    # Standard output (max 2,000 chars)
    "stderr":   str,    # Error output (max 500 chars)
    "language": str,
}
```

### Example exercise (produced by `generate_typed_exercises`)

```python
{
    "type":         "coding",
    "subject":      "cs",
    "difficulty":   "intermediate",
    "question":     "Complete the Python function to solve: Master: recursion.",
    "starter_code": "def solve(data):\n    \"\"\"Master: recursion\"\"\"\n    result = []\n    for item in data:\n        result.append(item)\n    return result\n\nprint(solve([1, 2, 3]))",
    "code_language": "python",
}
```

### Limits

- Timeout fixed at **5 seconds** — protects against infinite loops.
- Only Python is supported for now.
- The subprocess has **no access to the network** or project files.

## Tool 2 — `math_evaluator`

**File:** [math_evaluator.py](../backend/open_tutorai/tools/math_evaluator.py)

**Usage:** Mathematics (calculation, equations, derivatives, integrals, simplification), Sciences (formulas).

**Triggered when:** `type == "math"` OR `subject in ("math", "science")`, with `expression` or `answer` present.
→ Produced automatically by `generate_typed_exercises(subject="math")` and `generate_typed_exercises(subject="science", level="beginner"|"intermediate")`.

**Dependencies:** `sympy` (recommended) — numeric `eval()` fallback if absent.

### Automatic sympy expression selection

`generate_typed_exercises` selects the expression based on objective keywords:

| Detected keywords | Generated expression |
|---|---|
| derivative / diff | `diff(x**3 - 2*x**2 + x, x)` |
| integral | `integrate(x**2 + 1, x)` |
| equation / solve | `solve(x**2 - 4*x + 3, x)` |
| limit | `limit(sin(x)/x, x, 0)` |
| matrix | `Matrix([[1,2],[3,4]]).det()` |
| probability | `Rational(3, 4) * Rational(1, 2)` |
| factorial | `factorial(6)` |
| *(none)* → beginner | `2**8` |
| *(none)* → intermediate | `solve(x**2 - 5*x + 6, x)` |
| *(none)* → advanced | `integrate(x**3 - 2*x, x)` |

### Parameters

| Parameter | Type | Description |
|---|---|---|
| `expression` | `str` | Compatible sympy expression |
| `expected` | `str` | Expected result for verification (optional) |

### Return

```python
{
    "success": bool,
    "result":  str,          # result as a string
    "matched": bool | None,  # True if result == expected (None if no expected)
    "error":   str,
}
```

## Tool 3 — `generate_chart`

**File:** [generate_chart.py](../backend/open_tutorai/tools/generate_chart.py)

**Usage:** Mathematics (function plotting), Sciences (advanced curves), History (timeline).

**Triggered when:** `type == "chart"` with `chart_type` and `chart_payload` present.
→ Produced automatically by `generate_typed_exercises(subject="science", level="advanced")` and `generate_typed_exercises(subject="history")` (even exercises).

**Dependencies:** `matplotlib` — returns a clear error if absent.

### Automatically generated payloads

| Subject + level | chart_type | Payload content |
|---|---|---|
| `science` advanced | `function` | `{"expr": "sin(x)*exp(-x/5)", "x_min": 0, "x_max": 20}` |
| `history` (even) | `timeline` | `{"events": [{year, label}, ...], "title": ...}` |

### Parameters

| Parameter | Type | Description |
|---|---|---|
| `chart_type` | `str` | `'line'` \| `'bar'` \| `'scatter'` \| `'function'` \| `'timeline'` |
| `payload` | `str` | JSON describing the data |

### Payload schemas by chart_type

```json
// line / scatter
{"x": [1,2,3], "y": [4,5,6], "xlabel": "t (s)", "ylabel": "v (m/s)", "title": "Speed"}

// bar
{"labels": ["A","B","C"], "values": [10,20,15], "xlabel": "Category", "ylabel": "Frequency", "title": "Results"}

// function
{"expr": "x**2 - 2*x + 1", "x_min": -5, "x_max": 5, "title": "f(x) = x²-2x+1"}

// timeline
{"events": [{"year": 1789, "label": "French Revolution"}, {"year": 1815, "label": "Waterloo"}], "title": "Timeline"}
```

### Return

```python
{
    "success":   bool,
    "image_b64": str,   # PNG encoded in base64 — to display on the frontend
    "mime_type": str,   # "image/png"
    "error":     str,
}
```

### Frontend integration

```html
<img src="data:image/png;base64,{{ tool_result.image_b64 }}" />
```

## Tool 4 — `search_web`

**File:** [search_web.py](../backend/open_tutorai/tools/search_web.py)

**Usage:** All subjects — fact-checking, recent data, exercise enrichment.

**Triggered when:** `type in ("mcq", "explain")` AND `search_query` present.
→ Produced automatically by `generate_typed_exercises(subject="history")` (odd exercises) with `search_query = f"{obj} {topic}"`.

**Dependencies:** `duckduckgo-search` (already in `requirements.txt`).

### Parameters

| Parameter | Type | Description |
|---|---|---|
| `query` | `str` | Search query in natural language |
| `max_results` | `int` | Number of results (1–10, default 5; ExerciseAgent uses 3) |

### Return

```python
{
    "success": bool,
    "results": [
        {"title": str, "body": str, "href": str},
        ...
    ],
    "error": str,
}
```

### Pedagogical note

Snippets are injected into the exercise context to enrich the question or validate the answer. They are **not displayed raw** to the student — it is the FeedbackAgent's role to interpret them.

## Tool 5 — `grammar_checker`

**File:** [grammar_checker.py](../backend/open_tutorai/tools/grammar_checker.py)

**Usage:** Living languages — dictation, writing, translation, fill-in-the-blank.

**Triggered when:** `type == "dictation"` OR (`type in ("writing", "fill_in_blank")` AND `subject == "language"`).
→ Produced automatically by `generate_typed_exercises(subject="language")` with `sample_text` pre-filled based on level.

**Dependencies:** `openai` SDK + `OPENAI_API_KEY` variable. Supports Ollama via `OPENAI_BASE_URL`.

### Reference sentences automatically generated by level

| Level | Injected `sample_text` |
|---|---|
| `beginner` | `"Le chat mange du poisson."` |
| `intermediate` | `"Les élèves ont bien travaillé pendant toute la semaine."` |
| `advanced` | `"Bien que la situation fût complexe, ils parvinrent à trouver une solution élégante."` |

### Parameters

| Parameter | Type | Description |
|---|---|---|
| `text` | `str` | Student's text to correct |
| `language` | `str` | BCP-47 code (`'fr'`, `'en'`, `'ar'`, `'es'`, …) |

### Return

```python
{
    "success":        bool,
    "correct":        bool,        # True if no errors
    "errors":         list[str],   # list of described errors
    "corrected_text": str,         # corrected version
    "explanation":    str,         # pedagogical explanation in the student's language
    "error":          str,         # technical error if success == False
}
```

### Environment variables

| Variable | Role |
|---|---|
| `OPENAI_API_KEY` | OpenAI API key (required) |
| `OPENAI_BASE_URL` | Alternative base URL (Ollama, proxy) |
| `OPENAI_MODEL` | Model to use (default: `gpt-4o-mini`) |

## Enabling tools — quick guide

### Via the frontend (Source 1 — recommended)

Pass `subject` in the body of `POST /api/v1/adaptive/plan`:

```json
{
    "topic": "recursion",
    "subject": "cs",
    "current_level": "intermediate",
    ...
}
```

### Via topic only (Sources 2 & 3 — automatic)

If `subject` is absent, the `DiagnosticsAgent` calls `detect_subject(topic, weak_concepts)`.
Tools activate automatically if ≥ 2 subject keywords are present in the topic or `weak_concepts`.

```python
# Examples of topics that automatically activate tools
"recursion and sorting algorithms"  → subject="cs"  → live_code_evaluation
"derivatives and integrals"         → subject="math" → math_evaluator
"grammar and conjugation"           → subject="language" → grammar_checker
"revolution and world war"          → subject="history"  → generate_chart + search_web
```

### Verify in agent_trace

```python
"[DiagnosticsAgent] level=intermediate, 3 difficulties, subject=cs"
"[ExerciseAgent] 3 exercises (level=intermediate, subject=cs)"
"[ExerciseAgent] tools: live_code_evaluation, live_code_evaluation, live_code_evaluation"
```

## Adding a new tool

1. Create `backend/open_tutorai/tools/my_tool.py` with the `@tool` decorator.
2. Export it in [__init__.py](../backend/open_tutorai/tools/__init__.py).
3. Add a branch in `_run_tool_for_exercise()` in [exercise.py](../backend/open_tutorai/agents/langgraph/agents/exercise.py).
4. Optional: add a case in `generate_typed_exercises()` in [helpers.py](../backend/open_tutorai/agents/helpers.py) so the trigger field is produced automatically.
5. Document here: usage, trigger, parameters, return, exercise example.
